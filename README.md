# codev1od – Static demo

This is a static HTML/CSS/JS demo that reproduces the layout, animated background, floating blobs, and interactions similar to the reference site using original code and assets.

How to run locally:
1. Place all files in a folder (index.html, styles.css, script.js, assets/logo.svg).
2. Open `index.html` in a browser.

Deploy to GitHub Pages:
1. Create a new repository (for a user site name it `code1void.github.io` to publish to https://code1void.github.io).
2. Push files to the repository's default branch.
3. In GitHub repo Settings → Pages, ensure the default branch is selected. Page will be available shortly.
